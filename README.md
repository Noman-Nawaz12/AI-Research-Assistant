## 📌 Overview

**AI Research Assistant** is an intelligent multi-document analysis and question-answering system powered by Retrieval-Augmented Generation (RAG) and a specialized Dual LLM architecture.

Unlike simple single-file PDF readers, this assistant processes heterogeneous document formats (PDF, DOCX, TXT) into a unified vector space, enabling researchers and professionals to query across complex document collections seamlessly.

The system automatically:

✅ Extracts and parses multi-source text while preserving document metadata

✅ Chunks content dynamically using recursive text splitting

✅ Generates semantic vector embeddings using `all-MiniLM-L6-v2`

✅ Stores and queries vector representations via FAISS

✅ Summarizes retrieved context and chat history using **Mixtral 8x7B**

✅ Generates final structured answers with citations using **Llama 3.1 8B Instant**

## ⚡ Dual Groq LLM Architecture

To balance response quality with ultra-low latency, the workflow uses two specialized LLMs:

```
                  ┌───────────────────────────────┐
                  │    Retrieved Context Chunks   │
                  └──────────────┬────────────────┘
                                 │
                                 ▼
         ┌────────────────────────────────────────────────┐
         │   Model 1: Mixtral 8x7B (Context Summarizer)   │
         └───────────────────────┬────────────────────────┘
                                 │
                                 ▼
                     Summarized Context & History
                                 │
                                 ▼
      ┌──────────────────────────────────────────────────────┐
      │ Model 2: Llama 3.1 8B Instant (Final Answer Engine) │
      └──────────────────────────┬───────────────────────────┘
                                 │
                                 ▼
                   Grounded Answer with Citations

```

### Model Roles

1. **Mixtral 8x7B (Summarizer)**: Filters noise, removes redundant text from retrieved chunks, and compresses chat history to conserve token context.
2. **Llama 3.1 8B Instant (Generator)**: Synthesizes condensed context into structured, factual answers with explicit citations.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Noman-Nawaz12/ai-research-assistant.git
cd ai-research-assistant

```

Create a virtual environment:

```bash
python -m venv venv

```

Activate the environment:

* **Windows**:
```cmd
venv\Scripts\activate

```


* **Linux/macOS**:
```bash
source venv/bin/activate

```



Install dependencies:

```bash
pip install -r requirements.txt

```

---

# ▶️ Run Application

Launch the Streamlit web interface:

```bash
streamlit run app.py
```

Access the application in your browser at:

http://localhost:8501
